# 🛡️ Zona Accessories

Website resmi **Zona Accessories** — toko aksesori smartphone terpercaya, spesialis **hydrogel screen protector**, **backskin**, dan aksesori pelindung perangkat berkualitas.

---

## 🚀 Tech Stack

| Teknologi | Versi |
|-----------|-------|
| [Next.js](https://nextjs.org/) | 16.x |
| [React](https://react.dev/) | 19.x |
| [Tailwind CSS](https://tailwindcss.com/) | 4.x |
| [Framer Motion](https://www.framer.com/motion/) | 13.x |
| [Lucide React](https://lucide.dev/) | 1.47.x |
| [React Icons](https://react-icons.github.io/react-icons/) | 5.x |

## ⚙️ Cara Menjalankan Proyek

### Prasyarat

Pastikan sudah terinstall:
- **Node.js** versi `18.x` atau lebih baru → [Download Node.js](https://nodejs.org/)
- **npm** (sudah termasuk bersama Node.js)

> Cek versi dengan:
> ```bash
> node -v
> npm -v
> ```

---

### 1. Clone Repository

```bash
git clone https://github.com/natasha412020/zona-accessories.git
cd zona-accessories
```

---

### 2. Install Dependensi

```bash
npm install
```

---

### 3. Jalankan Mode Development

```bash
npm run dev
```

Buka browser dan akses: [http://localhost:3000](http://localhost:3000)

---

### 4. Build untuk Production

```bash
npm run build
npm run start
```

---

## 🧰 Scripts yang Tersedia

| Script | Perintah | Deskripsi |
|--------|----------|-----------|
| Development | `npm run dev` | Jalankan server lokal dengan hot-reload |
| Build | `npm run build` | Build proyek untuk production |
| Start | `npm run start` | Jalankan hasil build production |
| Lint | `npm run lint` | Cek kualitas kode dengan ESLint |

## 🌐 Deploy ke Vercel

Proyek ini siap di-deploy ke [Vercel](https://vercel.com/):

1. Buka [vercel.com](https://vercel.com/) dan login
2. Klik **"Add New Project"**
3. Import repository ini dari GitHub
4. Klik **"Deploy"** — selesai! ✅
